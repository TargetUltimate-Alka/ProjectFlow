# ProjectFlow Frontend Client

Single Page Application (SPA) built with React for Students, Faculty, and Admins.

## Features
- Dynamic portal switching based on user roles (Student, Faculty, Admin)
- Connects to API Gateway at `http://localhost:5000/api`
- Kanban board, requirements tracker, milestone submission forms, and GitHub sync metrics dashboard

## Running Locally
```bash
npm install
npm start
```
Runs at `http://localhost:3000`.
